# 首頁翻書與地圖操作調整

- 首頁四組原文與四張原照片維持順序，改為一次顯示一組。桌面是左圖右文的書本跨頁，以中央書脊為軸，右頁正面保留上一組文字、背面帶入下一張照片，旋轉180度後落到左側。回翻採相反方向；手機呈現單頁翻書。使用原生 CSS 3D 與 React，沒有新增依賴。
- 滾輪一次手勢只翻一頁，消化同次手勢的慣性事件；第四組之後可繼續正常捲動到後文，第一組向上亦不攔截。內容超過短視窗時先允許閱讀完整內容，再翻頁。觸控上下滑、章節連結和聚焦章節連結後的方向鍵／PageUp／PageDown皆可操作。
- 翻動用的圖文副本為 inert 且對輔助科技隱藏，原始四組內容保留在各自 article；減少動態效果偏好改為直接換頁。四組主標共用同一字級，不依個別句長縮字。
- 全站主背景、導覽、手機選單與頁尾統一為使用者指定的 #f5f4f2。
- 地圖的滑鼠浮起狀態與已點擊的介紹分開管理。移入浮起、移出落下；滑過、Tab焦點和Escape不更換已點擊內容。初次不顯示介紹或載入Google iframe，點擊／觸控／Enter／空白鍵／索引選取後保留至下一次選取。

驗證使用 `pnpm test`、`pnpm typecheck`、`pnpm lint`、Pages正式建置與匯出檢查，以及 `pnpm test:map`、`pnpm test:home-story`。瀏覽器檢查涵蓋1440、1281（高度552）、1280、1024、768、430、390、360px；截圖與JSON報告存於忽略的work目錄。首頁測試涵蓋翻書中間畫格、所有四組的字級和邊界、連續滾輪慣性、雙向操作、離開書本、觸控與減少動態效果。
