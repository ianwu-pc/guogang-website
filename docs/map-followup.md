# 地圖標記回饋修正（2026-09-08）

使用者在 1281 × 552 視窗指出右側小倆口福利社與暖江步道被裁切，並要求宋體底色標籤、地點介紹及可連至 Google Maps 的嵌入小地圖。

## 修正

- 依後續指定，整站背景改為 `#f5f4f2`，導覽列、手機選單、頁尾與地點索引統一使用 `--paper`。
- 原因是地圖一律 `min-width: 1200px`，超過當時約 1137px 的容器。1024px 以上改為完整貼合容器，維持原圖 16:9；窄螢幕保留 1100px 畫布與容器內拖曳，確保字可讀。
- 容器提供頂部與兩側安全空間，選單、點擊或鍵盤選取時，以「建築＋名稱」聯集邊界定位。新增檢查同時涵蓋頁面溢出與選取物件是否在地圖可見範圍內。
- 14 個外部名稱統一使用全站 `--serif`、14px。依後續回饋移除外框，改為稍深的不規則半透明色塊（暖棕底68%不透明度、活躍狀態綠底73%），保持標籤尺寸與位置。微調中排 4 個標籤水平位置。原圖的手繪路名與招牌保留。
- 介紹區左側為原插畫縮圖、名稱、介紹、地址與來源，右側為實際 Google Maps iframe 與獨立「在 Google 地圖中開啟」連結；700px 以下改為單欄。
- 建築僅在滑鼠移入時浮起，移開即降下；初次載入不顯示介紹。點擊、觸控點選、鍵盤 Enter／空白鍵或地點索引選取才更新介紹，並保留至下一次選取。滑過其他建築、移出地圖及鍵盤焦點移動皆不更換內容，也不預載 Google iframe。
- 地圖開頭與全部14項介紹採使用者提供的 `建築物文字敘述.docx`，逐字匯入 `app/data/guogangMapCopy.json`。保留52行原文與段落關係，北方大陸餅保留兩段。檔案 SHA-256：`1bc42179e4c50455b8decba98e89dd9f510e471ff4d4409279f1c417ba1ff42b`。
- `app/data/guogangMapDetails.ts` 僅管理位置與地圖來源。先前擬寫的介紹已由文件原文完整取代；未把網路改寫內容混入使用者的段落。
- 原有地圖開頭的1個標題與1段說明由文件開頭取代，其餘原有頁面與人物全文不改寫。歷史文字檢查 fixture 保留，兩項授權替換在測試中明示；新增來源雜湊 fixture 確保文件原文不被改寫。
- 未新增第三方照片、API key、地圖 JavaScript SDK 或套件。

## 來源與位置界線

地點與位置參考來源保存在地點資料中，也呈現於介紹下方；介紹原文的來源是使用者的 DOCX。地址補充核對包含過港幼兒園官方園站、浸信會聯會教會通訊錄及市府公園資料。

- 小倆口、美食坊、北方大陸餅：基隆市衛生局公開店家／食品資料。
- 暖江國小、過港幼兒園：校方簡介與園史。
- 黃蠟石文化館：基隆旅遊網，正式門牌為過港路52號。
- 聖光堂：教會服務介紹；過港堂門牌採浸信會通訊錄之過港路92號（安心學園服務據點另有88號，未混用）。
- 協會：既有網站介紹與聯絡資料。
- 郵局：中華郵政。
- 暖江兒童公園：市府刊物與公園名錄。
- 暖新住民會館：市立圖書館揭幕活動及市府公開資料。
- 過港福德宮：內政部寺院宮廟調查。
- 暖江步道：蹲點台灣過港走讀紀錄；小地圖採暖江橋河濱公園周邊定位，於介面明示。
- 舊警察宿舍：既有過港歷史與市府公有宿舍研究可確認聚落背景，未查得可確認的確切門牌／入口；小地圖只標示寧靜街周邊，於介面明示，未假造座標。

## 驗證

`pnpm test:map` 使用既有 Playwright 環境，檢查 1440、1281、1280、1024、768、430、390、360px，其中 1281px 的視窗高度為使用者原報告的552px。包含 14 地標逐項字型／底色、介紹／地圖連結同步、標籤交集、選中物件可見邊界及桌面完整地圖。

版面矩陣隔離第三方地圖網路，Google 實際嵌入另行載入驗證；不把隔離版面的空白 iframe 當作 Google 成功載入的證據。截圖與機器報告位於忽略的 `work/map-followup-qa/`。原有正文／路由驗證、TypeScript、lint 與 GitHub Pages 匯出檢查一起執行。
