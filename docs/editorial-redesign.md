# 過港網站編輯式改版驗收紀錄

日期：2026-09-08。以下為首輪本機驗收紀錄；本次發布與地圖順序更正見末節。

## 視覺改版

以 https://xiwei.webflow.io/ 的左右分幅、留白、明體層級、錯落照片與安靜的章節節奏為主要參考。未使用其文字、標誌、照片或插圖；相似程度屬視覺判斷，未以百分比宣稱測量結果。

- 首頁：原有四張照片／四段文字改成可直接閱讀的編輯式場景，分幅開場、偏置大圖及兩組不同寬度的圖文。章節索引仍可跳轉並反映閱讀位置。
- 內頁：白底標題與照片分離；認識過港採年代索引與閱讀欄，人物採六篇具真實照片的錯落專題，好味採不同尺寸產品照片與完整文案，協會頁使用橫幅與人物照片組合。
- 文章：保留六篇人物完整全文與照片，以及五篇好味詳細頁；閱讀欄、引用、段落編號、圖輯與相鄰文章導覽使用共用規則。
- 共用：`SiteHeader`、`SiteFooter`、`PageIntro`、`HomeScrollStory`、`HeadingLines`、`LineAction` 與全站 `globals.css`。
- 字體／間距：hero、page、section、card、name、article title、article section、body、label 各有共用 token。相同角色不因文字長度個別縮小。內文桌機 17px、手機 16px；地圖所有名稱固定同級 13px。

900px 以下改用可鍵盤操作的選單；700px 以下以單欄閱讀和偏置照片重組，保留照片比例及臉部；長標題用語意詞組提供換行點，文字本身不改寫。

- 新底圖與 14 張獨立 RGBA PNG 完全替代舊圖的渲染。原有舊地圖素材未被其他頁面使用，保留檔案但不載入。
- 以新圖重新量測百分比位置，畫布維持 16:9。窄螢幕只在地圖容器內水平平移，最小畫布寬 1200px，並提供地點索引快速定位。

## 文案變更清單

**原有正文、故事、標題、產品描述及歷史資訊：沒有改寫、刪減或摘要。** 16 條路由的 670 筆原有段落／標題經文字正規化與 SHA-256 比對通過；六篇人物全文另通過原有來源完整性檢查。`site.ts`、`peopleStories.ts`、`peopleStoryPhotos.ts` 未修改。

呈現／操作文字的變化如下：

- 中文標題只調整斷行與語意分組，例如「藏在每個人的／日常裡。」、「過港不是一個／突然出現的名字，」。連接後的文字與標點不變。
- 原有章節號、照片說明及英文章節文字改放到索引或圖說；內容不變。
- 地標名稱採使用者指定的 14 項及確認的建築對應。新增地圖操作文案：「地點索引」、「選擇地點」、「← 左右拖曳地圖 →」、「PLACE NOTE」、「認識協會 →」，以及「在地圖上輕觸建築，閱讀地點註記。」觸控提示與「查看〔地標名稱〕介紹」無障礙名稱；不新增地點歷史或描述。
- 新的獨立頁首照片增加替代文字：「過港河岸的地景」、「生活在過港的人們」、「過港社區的手作好味」、「過港社區的建築入口」。新增「繼續閱讀〔頁面名稱〕」無障礙導覽名稱。
- 原有 LINE 尚未提供訊息、待提供照片與網站資訊提示均保留。

## 保留的限制

原站尚未提供的 LINE URL、部分年代照片及網站資訊／隱私權正文仍維持待提供，未捏造內容。瀏覽器檢查使用 Chromium 與模擬觸控，未宣稱實體手機或其他瀏覽器驗收。地圖用原圖拆圖與局部背景重建；不改變其非地理測量的插畫性質。

Worker 的 runtime 型別由已安裝 Wrangler 正式產生，DB 依原有可選 binding 邏輯宣告；部署設定與依賴版本不變。首輪驗收時，Git 工作目錄保留原有未提交素材與改版變更，當時尚未 stage、commit、push 或部署。
