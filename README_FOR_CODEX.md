## 一、網站名稱與定位

網站名稱：

過港

網站角色：

這是一個以「地方、物產、人物與生活」為核心的地方文化網站。

網站一開始不要急著強調「過港社區發展協會」，而是先讓訪客：

- 看見過港
- 認識過港的名字與歷史
- 認識生活在這裡的人
- 看見地方好物與製作者
- 閱讀社區日常與故事

直到網站後段，才正式介紹「過港社區發展協會」以及協會在地方所扮演的角色。

網站主要目的：

- 讓外地人認識過港
- 呈現過港的地方特色
- 保存與分享地方記憶
- 介紹地方好物與製作者
- 呈現居民及社區人物故事
- 分享長者、孩子、環境與活動的社區故事
- 建立協會對外聯繫與加入 LINE 的入口

整體氣質：

- 有土地感
- 有人情味
- 真誠、自然、樸實
- 像一本可以慢慢閱讀的地方刊物
- 有現代設計感，但不要過度商業化
- 不要像政府機關網站
- 不要像制式協會網站
- 不要像新創公司 Landing Page
- 不要使用過多科技感、玻璃效果或漸層
